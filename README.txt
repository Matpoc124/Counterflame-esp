COUNTERFLAME ESP LAB — PWA demo

Это отдельная демонстрационная веб-страница с условными ботами.
Она НЕ подключается к CounterFlame и не считывает данные игры.

Проверка на ПК:
1. Распакуйте архив.
2. Откройте папку в VS Code.
3. Установите расширение Live Server.
4. Нажмите правой кнопкой на index.html -> Open with Live Server.

Установка на Android:
1. Для установки PWA сайт должен открываться по HTTPS (или localhost на самом устройстве).
2. Разместите файлы на HTTPS-хостинге (например, GitHub Pages или Netlify).
3. Откройте адрес сайта в Chrome на телефоне.
4. Меню Chrome -> Установить приложение / Добавить на главный экран.

Для проверки с телефона в одной Wi-Fi сети можно открыть адрес Live Server с IP компьютера,
но для установки PWA нужен HTTPS-сайт.
